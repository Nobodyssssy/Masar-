# Using Masar (مسار)

Launch the installed app and open Recherche. Choose sources, keywords, locations and publication/language/workload criteria. Leave personal eligibility disabled for broad searches. Click Rechercher les offres and read each source report.

The current Search publication window carries into Review. One day uses rolling 24 hours for timestamps; date-only advertisements must be dated today. Collection date never makes an old publication recent. Unknown dates require explicit inclusion. Historique complet intentionally removes visibility filters and says so.

Historical eligibility counts are not recommendations. Unverified jobs remain reviewable, including jobs without enough metadata for a personal-rule verdict. Profiles and optional personal rules can be saved, duplicated, renamed, imported/exported or removed without deleting jobs.

In Review, J/K navigate, A approves where allowed, S skips, L defers and Z undoes reversible triage. Approval of a personally excluded vacancy is manual; this build still requires a description for promotion. Read the original advertisement yourself. Applications and emails are never submitted automatically.

Record applications, document references, contacts and dates manually in Candidatures; use Relances/Calendar for reminders. The weekday reminder rule does not calculate cantonal holidays.

SwissDevJobs and eFinancialCareers use optional Firefox. Settings → Data provides install/repair. The installed app bundles Node/Playwright; collection does not require project-local dependencies or global Node. Offline tracking remains available.

The stable database is `%APPDATA%\ch.local.jobup.desktop\jobup.sqlite3`. Prefer the app's backup/restore controls. See DEVELOPMENT-AND-RECOVERY.md for recovery and development instructions. Never overwrite a database while the app is open.

This is a development build. See VERIFICATION-REPORT.md for tested behaviour and remaining gaps.
